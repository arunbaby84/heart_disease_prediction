# EDA Output Screenshots

This folder stores exported exploratory data analysis (EDA) figures generated by the project pipeline.

## Included plots

- `eda_summary.png` — Age, cholesterol, maximum heart rate, and class balance summary
- `feature_correlation.png` — Feature correlation heatmap for the heart disease dataset
- `feature_boxplots.png` — Box plots for the continuous variables to reveal spread and possible outliers
- `target_boxplots.png` — Feature distributions grouped by heart disease target to show class-specific nuance
- `feature_scatterplots.png` — Scatterplots for key feature relationships and separation patterns
- `feature_pairplot.png` — Pairwise feature relationships with target-based color coding

## Outlier check

The script also prints an IQR-based outlier summary to the terminal, highlighting which continuous features show unusually large or small values.
